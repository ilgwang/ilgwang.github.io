템플릿 정보만 전송 시 장비가 생체정보를 저장하지 않는 이슈

문제

템플릿만 전송 시 장비는 등록 성공을 응답하지만, 장비에는 생체 정보를 저장하지 않아 인증 실패

원인

생체정보를 빼고 전송했지만 데이터에 '생체정보 포함' 표시가 남아 있어, 장비가 생체 정보를 저장하지 않고 있음을 발견

해결

전송 전 '생체정보 포함' 표시를 끄고 '템플릿 전용' 표시만 남도록 flag 변환

결과

템플릿만으로 시설 장비 등록 · 1:N 인증 성공, 회수까지 검증

한 사람의 생체 정보가 여러 번 저장되어, 인증이 되지 않는 이슈

문제

장비에서 직접 등록 시 생체 정보에 대한 중복체크를 자체적으로 하지만, 웹으로 등록 시 중복체크를 진행하지 않아 같은 사람의 생체 정보가 여러 번 저장되어 인증이 되지 않는 이슈 발견

원인

장비 템플릿 형식이 비공개라 서버에서 중복 여부를 판단할 수 없음을 확인

해결

장비 템플릿 대신 서버에서 직접 생체 특징값을 추출하는 중복 검사 기능을 웹 등록 과정에 추가

결과

웹 등록에서도 중복 등록이 차단되어, 같은 사람의 생체 정보가 여러 번 저장되지 않고 있음을 확인

검증 결과

  • 다른 사람 12쌍의 유사도 0.032 – 0.323, 같은 사람 9쌍 0.394 – 0.965
  • 두 구간이 겹치지 않는 지점에 차단 기준 0.363을 둠
  • 실제 중복 등록 시도(유사도 0.858)가 차단됨 · 등록자 7명 비교에 108 ms

장비와 서버의 시간 기준이 달라 출입 허용 시간이 어긋나는 이슈

문제

당일 이용 기간으로 등록한 사용자가 장비에서 '유효기간 만료'로 인증이 거부되는 이슈 발견

원인

장비는 세계 표준시(UTC)로 시간을 보내면서, 받은 시간은 한국 시간으로 해석함을 확인

해결

당일 이용 기간을 한국 시간 기준으로 변환하여 전송

결과

당일 이용 기간 안에는 정상 인증되고, 기간이 지나면 '유효기간 만료'를 표시하며 인증 차단됨을 확인

기타 연동 이슈 · 시험 중 함께 찾아 조치한 문제

현상원인조치
사용자 등록 후 인증 과정에서 서버 인증 단계에서 거부되고 있음을 확인장비에서 사용자 정보를 삭제 시 서버 DB의 사용자 정보까지 함께 삭제됨을 확인장비에서 사용자 정보를 삭제 시, 삭제 정보가 서버 DB에는 반영되지 않도록 조치
장비 관리자로 지정된 사용자를 웹에서 재등록 시 일반 사용자로 바뀌고 있음을 확인재등록 시 권한 정보가 기본값(일반 사용자)으로 덮어써지고 있음을 확인웹에서 재등록 시, 기존 권한 정보가 그대로 유지되도록 조치
로비폰으로 생체 정보 전송 시 연결이 끊겼다 다시 붙기를 반복하고 있음을 확인한 번에 보내는 데이터(47 KB)가 메시지 브로커의 최대 크기(8 KB)를 넘고 있음을 확인브로커 최대 크기를 늘리고, 전송 데이터도 6.9 KB로 줄이도록 조치
Windows에서 작성한 설치 스크립트가 Rocky Linux에서 실행되지 않고 있음을 확인줄바꿈 형식이 Windows 방식(CRLF)이라 Linux에서 명령을 인식하지 못하고 있음을 확인줄바꿈을 Linux 방식(LF)으로 통일하고, 실행 전 문법 검사를 추가하도록 조치

GitLab 변경 내용이 그래프에 반영되지 않는 이슈

문제

Webhook으로 변경된 파일 경로는 받았지만, 파일 내용을 가져오지 못해 그래프에 반영되지 않는 이슈 발견

원인

Webhook은 파일 경로만 보내고, 배포망은 GitLab → 서버 방향만 열려 있어 서버가 GitLab에 파일 내용을 요청할 수 없음을 확인

해결

GitLab의 post-receive 훅이 push 시 변경된 CSV 내용까지 담아 전송하도록 변경하여, 서버가 GitLab에 다시 요청하지 않도록 조치

결과

push 후 약 1.2초 만에 변경 내용이 그래프에 반영되고, 훅 오류가 발생해도 push는 정상 완료됨을 확인

CSV 변경 내용이 그래프에 반영되지 않던 이슈

문제

데이터 변경 알림을 받으면 기존 데이터를 삭제하지 않고 변경된 데이터를 추가로 등록해, 토폴로지가 깨지는 이슈 발견

원인

그래프 적재가 연결을 추가 · 갱신만 하고, CSV에서 사라진 연결은 삭제하지 않음을 확인

해결

적재 후 CSV에 없는 연결을 삭제하는 정리 단계를 추가하고, 과도한 삭제를 막는 예외 처리 적용

결과

CSV를 바꾸거나 되돌려도 그래프가 CSV와 같은 연결 상태로 유지됨을 확인

예외 처리

  • CSV가 비어 있으면 정리 단계 건너뜀
  • 20% 넘게 삭제하려 하면 전체 취소
  • 장비 · 인터페이스는 삭제하지 않음

수집 서버 처리 속도가 느려 변경 데이터가 밀리는 이슈

문제

Nautobot 변경 데이터가 Kafka에 계속 쌓이는데, 수집 서버가 초당 5건만 처리해 975만 건이 밀리는 이슈 발견

원인
